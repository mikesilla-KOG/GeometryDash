# Geometry Dash Neon Rush

Geometry Dash Neon Rush is a self-contained HTML5 Canvas browser game inspired by the rhythm-platforming feel of Geometry Dash. It runs instantly in a modern browser with no build step, no dependencies, and no server required.

## How to Play

1. Open `index.html` from your local clone in any modern browser.
2. Press **Start Game**.
3. Controls:
   - **Space / Click / Tap**: jump, thrust, or flip gravity depending on form
   - **P**: pause or resume
   - **R**: restart after game over

## Gameplay Features

- Endless side-scrolling neon rhythm gameplay
- Three forms:
  - **Cube**: classic jump with a hold-to-jump-higher feel
  - **Ship**: hold to fly upward, release to drop
  - **Ball**: flip gravity between floor and ceiling
- Procedural obstacle generation with spikes, blocks, platforms, and form portals
- Speed ramps up over time and pulses with the beat
- Synthesized background music generated with Web Audio
- Parallax backgrounds, score tracking, pause support, and local high score saving
- Keyboard, mouse, and mobile touch support

## Project Structure

- `index.html` – complete game, styles, UI, canvas rendering, audio, and gameplay logic

## GitHub Pages Deployment

1. Push the repository to GitHub.
2. In GitHub, open **Settings** → **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your default branch and the `/ (root)` folder.
5. Save the settings.
6. GitHub Pages will publish `index.html` automatically.
